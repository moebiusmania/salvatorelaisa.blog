<snow-fall>

A dependency-free snowfall web component: three depth layers of flakes, animated with CSS only. The same snow that falls on salvatorelaisa.blog at Christmas.

Your system asks for reduced motion, so the snow is hidden on purpose. Disable that setting to see the demo.

Try it

42
Layer
Page

Contained

With the contained attribute the snow fills its nearest positioned ancestor instead of the viewport.

🎄

Usage

<script type="module" src="snow-fall.js"></script>

<snow-fall></snow-fall>

<!-- 80 flakes, behind the content, tinted for a light page -->
<snow-fall count="80"
  style="--snow-z-index: -1; --snow-color: #b9cdd8"></snow-fall>

<!-- inside a box -->
<div style="position: relative; overflow: hidden; height: 16rem">
  <snow-fall contained count="30"></snow-fall>
</div>
OptionDefaultDescription
count42Number of flakes, capped at 300.
containedoffFill the nearest positioned ancestor instead of the viewport.
--snow-color#fffFlake colour.
--snow-glowblue-greyHalo around each flake; keeps white snow visible on light pages.
--snow-z-index9999Stacking order; -1 lets the snow fall behind the content.
